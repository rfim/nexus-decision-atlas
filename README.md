# Nexus Decision Atlas

The 50 models from *The Decision Book* (Krogerus & Tschäppeler), redrawn as simple diagrams and summarised, each with an analogy for building a data platform.

Type your own stack (sources, ingestion, storage, transform, orchestration, serving, ML, governance) at the top of the page and every analogy rewrites itself around your tools. A finder ranks the models that fit a decision you describe in a sentence.

One static file: `index.html`. No build step.

## Publish on GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: `main`, folder `/ (root)`.

The summaries are original retellings for study; the models belong to their original authors.
